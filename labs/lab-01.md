# Лабораторна робота №1

**Тема:** Основи SQL. Створення бази даних та виконання запитів у Supabase.

**Мета роботи:** Ознайомитися з основами мови SQL, навчитися створювати та заповнювати таблиці бази даних, виконувати запити для вибірки, фільтрації та сортування даних.

## 1. Використане програмне забезпечення

- Supabase — для створення та роботи з базою даних.
- SQL Editor — для написання та виконання SQL-запитів.
- GitHub — для збереження результатів лабораторної роботи.

## 2. Створення бази даних

Для виконання лабораторної роботи було створено проєкт `lab01-technomart` у середовищі Supabase та імпортовано файл `technomart.sql`.

У результаті було створено та заповнено 8 таблиць:

- regions — 25 записів;
- suppliers — 8 записів;
- categories — 10 записів;
- products — 25 записів;
- employees — 8 записів;
- customers — 15 записів;
- orders — 31 запис;
- order_items — 47 записів.
