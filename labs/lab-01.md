5. Контрольні запитання
1. Що таке SQL і для чого він призначений? Поясніть різницю між декларативною та імперативною мовами програмування на прикладі SQL.

SQL — це мова структурованих запитів, яка використовується для роботи з реляційними базами даних. За її допомогою можна отримувати, додавати, змінювати та видаляти дані. SQL є декларативною мовою, оскільки користувач вказує, який результат потрібно отримати, а не описує кожен крок його виконання. В імперативних мовах програмування потрібно задавати послідовність дій.

2. Опишіть порядок виконання частин SELECT-запиту. Чому важливо розуміти цю послідовність при написанні складних запитів?

Основний логічний порядок виконання: FROM, WHERE, SELECT, ORDER BY, LIMIT. Спочатку визначається таблиця, потім відбираються потрібні записи, вибираються стовпці, результати сортуються та обмежуються. Розуміння цього порядку допомагає правильно складати складні запити.

3. У чому різниця між операторами = та LIKE? Наведіть приклади, коли доцільно використовувати кожен із них.

Оператор = перевіряє повну відповідність значення. Наприклад, city = 'Київ' знаходить клієнтів із Києва. Оператор LIKE використовується для пошуку за шаблоном. Наприклад, contact_name LIKE 'Іван%' знаходить імена, які починаються на «Іван».

4. Поясніть призначення wildcards % та _ в операторі LIKE. Чи можна їх комбінувати в одному шаблоні?

Символ % замінює будь-яку кількість символів, а _ — один будь-який символ. Їх можна комбінувати в одному шаблоні. Наприклад, LIKE 'Ів_н%' шукає текст, який відповідає заданому шаблону.

5. Чому оператор WHERE company_name = NULL не працює для пошуку записів з відсутніми значеннями? Як правильно працювати з NULL значеннями в SQL?

NULL означає відсутність або невідомість значення. Його не можна перевіряти за допомогою звичайного оператора рівності. Для цього використовують IS NULL або IS NOT NULL. Перший знаходить записи без значення, а другий — записи, у яких значення присутнє.

6. Поясніть різницю між логічними операторами AND та OR. Як впливає пріоритет операторів на результат запиту A OR B AND C?

AND означає, що всі умови мають бути виконані. OR означає, що достатньо виконання хоча б однієї умови. Оператор AND має вищий пріоритет за OR, тому вираз A OR B AND C виконується як A OR (B AND C). Для правильного групування умов використовують дужки.

7. У яких випадках оператор BETWEEN включає граничні значення, а в яких — ні? Як написати умову для виключення границь діапазону?

Оператор BETWEEN включає обидві межі діапазону. Наприклад, unit_price BETWEEN 10000 AND 30000 включає товари з ціною 10000 і 30000. Щоб виключити межі, потрібно використовувати unit_price > 10000 AND unit_price < 30000.

8. Для чого використовується LIMIT та OFFSET? Напишіть формулу для розрахунку OFFSET при пагінації, якщо відома сторінка та розмір сторінки.

LIMIT обмежує кількість записів, які повертає запит. OFFSET пропускає задану кількість записів. Формула: OFFSET = (номер сторінки - 1) × розмір сторінки. Наприклад, для другої сторінки з 10 записами використовується OFFSET 10.

9. Чому важливо використовувати ORDER BY разом з LIMIT? Що може статися, якщо не вказати сортування при обмеженні кількості записів?

ORDER BY забезпечує потрібний порядок записів. Якщо використовувати LIMIT без сортування, база даних може повертати записи в непередбачуваному порядку. Тому для отримання конкретних перших або останніх записів сортування є важливим.

10. Поясніть різницю між LIKE та ILIKE в PostgreSQL. В яких ситуаціях кожен з них буде більш доцільним?

LIKE виконує пошук із врахуванням регістру символів. ILIKE виконує пошук без врахування регістру. LIKE доцільно використовувати, коли важливий точний регістр, а ILIKE — коли потрібно знайти текст незалежно від великих чи малих літер.

11. Як PostgreSQL обробляє NULL значення при сортуванні за замовчуванням? Як це можна змінити за допомогою NULLS FIRST/LAST?

За замовчуванням PostgreSQL розміщує NULL наприкінці при сортуванні за зростанням і на початку при сортуванні за спаданням. За допомогою NULLS FIRST можна розмістити порожні значення на початку, а NULLS LAST — наприкінці.

12. Наведіть приклад бізнес-сценарію, де потрібно використати складну комбінацію умов з дужками. Поясніть, як неправильне групування логічних операторів може призвести до некоректних результатів.

Наприклад, інтернет-магазин хоче знайти товари двох категорій, які коштують дорожче 20000 грн. Для цього можна використати запит:

SQL
SELECT *
FROM products
WHERE (category_id = 1 OR category_id = 2)
  AND unit_price > 20000;
Дужки об'єднують умови вибору категорій. Якщо їх не використати, через вищий пріоритет AND частина товарів першої категорії може потрапити до результату незалежно від ціни. Це призведе до неправильного відбору даних.

6. Висновок
Під час виконання лабораторної роботи було створено та налаштовано базу даних Technomart у середовищі Supabase. Було досліджено структуру таблиць і виконано SQL-запити для отримання, фільтрації, сортування та обмеження даних.

У процесі роботи було використано оператори SELECT, WHERE, LIKE, AND, OR, NOT, IN, BETWEEN, IS NULL, IS NOT NULL, ORDER BY, LIMIT та OFFSET.

Також було виконано комбіновані запити, сортування за кількома полями та пагінацію результатів. У результаті закріплено практичні навички роботи з PostgreSQL та основами мови SQL.
